# Project Brief

## Название
Polemica Fantasy

## Цель
Сервис для создания фэнтези-команд по игре «спортивная мафия». Пользователи собирают карточки реальных игроков и соревнуются, выставляя команды из 1–3 карточек на серии игр (неполный состав уменьшает награду за место пропорционально).

## Scope

### В scope:
- Бэкенд (REST API) на Spring Boot / Kotlin / PostgreSQL
- Telegram Mini App для пользователей (просмотр турниров, карточек, сборка команд)
- Отдельная веб-админка (управление турнирами, сериями, карточками, паками)
- Интеграция с Polemica API через polemica-library (получение игр и игроков)
- Система карточек с редкостями и перками
- Система рандомных паков карточек
- Скоринг фэнтези-команд по результатам реальных игр
- Лидерборд по сериям

### Вне scope (на данном этапе):
- Платёжная система / монетизация
- Обмен/продажа карточек между пользователями
- Push-уведомления
- Real-time обновление очков (пока ручной запуск через админку)

## Ключевые требования
1. Данные об играх и игроках берутся из Polemica API
2. Турниры — собственная сущность сервиса; поле **`kind`**: `STANDALONE` (без привязки к соревнованию Polemica) или `POLEMICA_COMPETITION` (на турнире хранится `polemica_competition_id`). Все серии одного турнира одного типа.
3. Серия: при `STANDALONE` — матчинг игр по `name_prefix` и профилям участников; при `POLEMICA_COMPETITION` — диапазон номеров игр (`game_num_from` / `game_num_to`) внутри соревнования Polemica, sync через `getGamesFromCompetition`.
4. Карточки выдаются только через администратора (вручную или через паки)
5. У пользователя может быть несколько одинаковых карточек
6. Шаблон карточки привязан к глобальному игроку (`fantasy_player`, один на `polemica_user_id`), а не к участнику одного турнира; карточка может использоваться в разных турнирах, если игрок включён в состав серии
7. Карточки имеют уровень редкости (COMMON, RARE, EPIC, LEGENDARY)
8. Фэнтези-команда = 1–3 карточки на серию (неполный состав: награда за место в лидерборде — ⌈⅓⌉ или ⌈⅔⌉ от конфига, округление вверх)
9. Очки = базовые очки игрока + бонусы за перки карточки
