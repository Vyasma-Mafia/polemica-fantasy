# Product Context

## Зачем этот проект?
Спортивная мафия — популярная интеллектуальная игра с активным турнирным сообществом. Polemica — основная платформа для учёта игр и рейтингов. Однако взаимодействие зрителей/болельщиков с турнирами ограничено — они могут только смотреть результаты.

Polemica Fantasy добавляет геймификацию: пользователи собирают карточки игроков и составляют фэнтези-команды, получая очки за реальные достижения выбранных игроков. Это повышает вовлечённость аудитории и интерес к просмотру турниров.

## Целевая аудитория
- Болельщики/зрители турниров по спортивной мафии
- Сами игроки (смотрят серии, в которых не участвуют)
- Организаторы турниров (создают турниры и управляют ими)

## UX-цели
- **Простой вход:** Telegram Mini App — не нужна установка, регистрация через Telegram
- **Понятная механика:** посмотрел турнир → выбрал 3 карточки → следишь за очками
- **Коллекционирование:** карточки с разными редкостями мотивируют собирать коллекцию; в TMA на карточке показывается фото игрока, рамка визуально отражает редкость
- **Социальность:** лидерборд, сравнение с друзьями

## User Journeys

### Пользователь
1. Открывает Mini App в Telegram
2. Видит список активных турниров
3. Заходит в турнир → видит серии
4. В серии видит доступных игроков
5. Выбирает 3 карточки из своей коллекции
6. После игр — видит набранные очки и позицию в лидерборде

### Администратор
1. Создаёт турнир, добавляет игроков (по Polemica ID) — для каждого создаётся или подставляется глобальный `fantasy_player`
2. Создаёт серии, назначает игроков из ростра турнира
3. Создаёт шаблоны карточек по **`fantasyPlayerId`** (редкость, достижения); шаблон не «принадлежит» турниру и может использоваться везде, где игрок в серии
4. Выдаёт карточки пользователям (напрямую или через паки; пак тянет случайные шаблоны из глобального пула по редкости)
5. После игр — синхронизирует игры и запускает расчёт очков
