# Glossary

Рабочий глоссарий проекта. Для кода используем точные имена сущностей и полей; для продуктового обсуждения используем русские термины из этого файла.

## Naming Rules

- **Пользователь** / `telegram_user` — человек, который открывает TMA, покупает паки, владеет картами и собирает команды. Не называть его "игроком", если речь не о реальном игроке в мафию.
- **Игрок** / `fantasy_player` — реальный игрок спортивной мафии из Polemica, представленный на карточках. В техническом контексте лучше писать `fantasy_player`, в продуктовом — "игрок".
- **Турнир** / `tournament` — внутренняя сущность Polemica Fantasy. **Соревнование Polemica** / `polemica_competition_id` — внешняя сущность Polemica. Не смешивать эти понятия.
- **Серия** / `series` — фэнтези-единица для набора игр, дедлайна состава, лиг и лидерборда. Не использовать "матч" как синоним серии.
- **Игра** / `PolemicaGame` / `series_game` — конкретная игра из Polemica. `series_game` — локальная привязка и JSONB-кэш этой игры к серии.
- **Синхронизация** (`sync`) — загрузка игр из Polemica и сохранение в `series_game`. **Скоринг** (`calculate`, `scoring`) — расчет очков. **Финализация** (`finalize`) — экономическое закрытие серии: списание uses, награды, `finalized = true`.
- **Карта** без уточнения неоднозначна. В модели различать **шаблон карты** (`card_template`) и **экземпляр карты пользователя** (`user_card`).
- **Ростер** — набор доступных реальных игроков. Для турнира это `tournament_player`, для серии — `series_player`. В UI можно писать "состав игроков", но в техническом обсуждении лучше уточнять уровень.

## Core Domain

| Термин | Код / источник | Каноническое значение |
|--------|----------------|-----------------------|
| Polemica Fantasy | проект | Фэнтези-сервис поверх реальных игр спортивной мафии из Polemica. |
| Polemica | внешняя платформа | Источник реальных игроков, соревнований, игр и игровых данных. |
| TMA | `polemica-fantasy-webapp` | Пользовательское Telegram Mini App. |
| Админка | `polemica-fantasy-admin` | Веб-интерфейс администрирования турниров, серий, карточек, паков, экономики и коммуникаций. |
| Backend | `polemica-fantasy-backend` | Kotlin/Spring Boot API для TMA и админки. |
| Турнир | `tournament` | Внутренний контейнер Polemica Fantasy: объединяет ростер игроков, серии и паки. |
| Тип турнира | `TournamentKind` | `STANDALONE` или `POLEMICA_COMPETITION`; все серии одного турнира одного типа. |
| Соревнование Polemica | `polemica_competition_id` | Внешнее соревнование Polemica, к которому может быть привязан внутренний турнир типа `POLEMICA_COMPETITION`. |
| Серия | `series` | Набор игр внутри турнира, на который пользователь собирает фэнтези-команду в одной или нескольких лигах. |
| Статус серии | `SeriesStatus` | `UPCOMING`, `ACTIVE`, `SCORING`, `FINISHED`; переход в `FINISHED` запускает финализацию, если серия еще не finalized. |
| Дедлайн состава | `team_deadline` | Момент, после которого пользователь не должен менять команду серии. |
| Игрок | `fantasy_player` | Глобальная запись реального игрока мафии: один `polemica_user_id`, ник, фото. |
| Участник турнира | `tournament_player` | Связь "турнир -> игрок"; определяет ростер турнира. |
| Игрок серии | `series_player` | Связь "серия -> участник турнира"; определяет, чьи карты можно поставить в команду серии. |
| Пользователь | `telegram_user` | Пользователь TMA: Telegram identity, баланс фантиков, настройки уведомлений, коллекция карт. |

## Series And Sync

| Термин | Код / источник | Каноническое значение |
|--------|----------------|-----------------------|
| `STANDALONE`-турнир | `TournamentKind.STANDALONE` | Серии не привязаны к соревнованию Polemica; игры подбираются по пересечению match id из профилей игроков, `name_prefix` и опционально `game_started_on`. |
| `POLEMICA_COMPETITION`-турнир | `TournamentKind.POLEMICA_COMPETITION` | Турнир привязан к соревнованию Polemica; серии выбирают игры по `game_num_from`/`game_num_to` и опционально `game_phase`. |
| Префикс серии | `series.name_prefix` | Фильтр названия игры для `STANDALONE`; обязателен для sync таких серий. |
| День игр серии | `series.game_started_on` | Опциональный фильтр `PolemicaGame.started.toLocalDate()` для `STANDALONE`; нужен, когда одинаковые или похожие префиксы повторяются в разные дни. |
| Диапазон игр | `game_num_from`, `game_num_to` | Inclusive-диапазон `num` из соревнования Polemica для `POLEMICA_COMPETITION`. |
| Фаза игры | `game_phase` | Опциональный фильтр phase `0..2` для `POLEMICA_COMPETITION`; `null` означает все фазы. |
| Игра серии | `series_game` | Локально сохраненная игра Polemica с `polemica_game_id`, названием, `played_at`, JSONB-кэшем и флагом `scored`. |
| Автосинхронизация | `ActiveSeriesSyncScheduler` | Каждые 10 минут синхронизирует и считает `ACTIVE`/`SCORING` серии, которые еще не finalized. |

## Cards And Collection

| Термин | Код / источник | Каноническое значение |
|--------|----------------|-----------------------|
| Шаблон карты | `card_template` | Определение карты: игрок (`fantasy_player`), редкость, арт fallback, описание и достижения. Не принадлежит конкретному пользователю. |
| Экземпляр карты | `user_card` | Конкретная карта в коллекции пользователя: владелец, шаблон, скин, контракт, источник пака, soft-delete. |
| Редкость | `Rarity` | `COMMON`, `RARE`, `EPIC`, `LEGENDARY`; влияет на score modifier, экономику и визуал. |
| Достижение | `achievement` | Справочник типов игровых событий; детекторы скоринга используют `achievement.id`. |
| Достижение на шаблоне | `card_template_achievement` | Привязка достижения к шаблону карты с опциональным override бонуса. |
| Скин карты | `card_skin`, `user_card.card_skin_id` | Косметика экземпляра карты; не влияет на скоринг и экономику. |
| Пак | `card_pack` | Набор для выдачи карт: manual/legacy или auto-generated; может продаваться в Store за фантики. |
| Контракт карты | `uses_remaining`, `times_renewed` | Сколько раз экземпляр карты еще может участвовать в финализированных лигах серий и сколько раз продлевался. |
| Переработка | `recycle` | Soft-delete экземпляра карты с начислением фантиков, если карта не участвует в незавершенной серии. |
| Продление | `renewal` | Платное восстановление uses для истекшей карты с лимитом количества продлений. |
| Легендарный апгрейд | `legendary-upgrade` | In-place EPIC -> LEGENDARY для того же `user_card`: новый шаблон, дополнительное достижение, списание фантиков. |

## Teams, Leagues, Scoring

| Термин | Код / источник | Каноническое значение |
|--------|----------------|-----------------------|
| Фэнтези-команда | `fantasy_team` | Команда пользователя на конкретную серию и лигу; состоит из 1-3 слотов с картами разных игроков. |
| Слот команды | `fantasy_team_card` | Позиция карты в команде. |
| Лига | `league` | Системная или будущая пользовательская лига; сейчас основные коды `MAIN` и `BUDGET`. |
| Лига серии | `series_league` | Включение и параметры конкретной лиги в конкретной серии: enabled, value cap override, reward scale override. |
| Основная лига | `MAIN` | Базовая лига без бюджетного ограничения. |
| Бюджетная лига | `BUDGET` | Лига с ограничением суммарной ценности команды (`value_cap`) и масштабированными наградами (`reward_scale`). |
| Лидерборд серии | endpoint серии/лиги | Рейтинг команд внутри одной серии и одной лиги. |
| Турнирный лидерборд | TMA aggregation | Сводный рейтинг по сериям турнира; исторически агрегируется на клиенте по MAIN. |
| Базовые очки | `base_points` | Очки игрока из `GamePointsService` по публичной странице Polemica match, не `PolemicaPlayer.award`. |
| Бонус достижений | `achievement_bonus` | Сумма бонусов за достижения карты, найденные в игре для этого игрока. |
| Модификатор редкости | `rarity_modifier` | Множитель редкости в формуле `(base_points + achievement_bonus) * rarity_modifier`. |
| Детализация по играм | `fantasy_team_card_game_score` | Persisted breakdown по каждой карте и игре серии. |
| Финализация серии | `SeriesFinalizationService` | Необратимое закрытие серии: награды по лигам, списание uses по числу лиг участия, уведомления, `finalized = true`. |

## Economy And Marketplace

| Термин | Код / источник | Каноническое значение |
|--------|----------------|-----------------------|
| Фантики | `telegram_user.fantiki` | Внутриигровая валюта; все операции пишутся в `fantiki_transaction`. |
| Economy config | `economy_config` | Key-value параметры экономики: uses, recycle/renewal, награды, цены marketplace, league reward scale/value cap. |
| Marketplace listing | `marketplace_listing` | Лот на продажу экземпляра карты; статусы вроде `ACTIVE`, `SOLD`, `CANCELLED`. |
| Сделка marketplace | SOLD listing | Факт продажи лота; для истории сохраняются snapshots шаблона/скина. |
| Комиссия marketplace | `marketplace.commission_percent` | Доля цены, удерживаемая сервисом при продаже. |
| Жалоба на сделку | `marketplace_complaint` | Пользовательская жалоба на SOLD-сделку marketplace. |
| Санкция сделки | `marketplace_listing_sanction` | Модераторское решение по конкретной сделке; используется также для идемпотентности pair ban. |
| Бан пары | `ban-pair` | Админская санкция против пары пользователей за перелив: списывает фантики по несанкционированным SOLD-листингам пары, но не удаляет карты и не отменяет лоты. |
| Бан marketplace | `marketplace_banned`, `marketplace_banned_until` | Ограничение пользователя на marketplace; не путать с `ban-pair`. |

## Terms To Avoid

- Не писать "игрок" про `telegram_user`, если рядом есть реальные Mafia players.
- Не писать "карта" в API/model discussion, когда важно отличить `card_template` от `user_card`.
- Не называть `POLEMICA_COMPETITION` "турниром Polemica Fantasy"; это внешний источник для внутреннего турнира.
- Не называть `sync` "скорингом" и не называть `finalize` "calculate scores".
- Не использовать "соревнование" как синоним внутреннего `tournament`, если контекст связан с Polemica API.
