# План 2: Ценность карт (frontend)

> **Предусловия:** План 1 (бэкенд отдаёт `value` в `UserCardItemDto` и `cardValues` в `EconomyInfoDto`)  
> **Результат:** TMA отображает ценность на карточках во всех контекстах, расшифровку в модалке  
> **Дизайн-документ:** §8.1 (Ценность на карточке), §5.3 (паки)

## Шаги

### 1. Типы: обновить `UserCardItem`

**Файл:** `polemica-fantasy-webapp/src/api/types.ts`

Добавить поле в интерфейс `UserCardItem`:

```typescript
value: number;
```

Добавить `cardValues` в `EconomyInfo`:

```typescript
cardValues: {
  baseValues: Record<Rarity, number>;
  achievementBonus: number;
};
```

### 2. Бейдж ценности на карточке в коллекции

**Файл:** `polemica-fantasy-webapp/src/pages/CardsPage.tsx`

На каждой карточке в гриде — компактный бейдж с ценностью, например `₱50`. Размещение: в углу карточки (аналогично бейджу uses).

Стиль бейджа:
- Маленький, не перекрывает картинку
- Цвет: нейтральный (например, полупрозрачный тёмный фон + белый текст)
- Символ ценности: `₱` или другой (§13 — открытый вопрос; пока `₱`)

### 3. Бейдж ценности в контексте маркетплейса

**Файл:** `polemica-fantasy-webapp/src/pages/MarketplacePage.tsx`

На карточке листинга рядом с ценой продавца — ценность карты для сравнения:

```
Цена: 200₣  |  Ценность: 50₱
```

Визуально различать цену (фантики) и ценность (₱) разными цветами/иконками.

### 4. Расшифровка ценности в модалке карточки

**Файл:** `polemica-fantasy-webapp/src/pages/CardsPage.tsx` (или выделить компонент)

В детальной модалке карточки (при тапе на карту в коллекции) — секция:

```
Ценность: 40 (редкость) + 10 (1 достижение) = 50₱
```

Данные для расшифровки:
- `baseValue` — из `economyInfo.cardValues.baseValues[card.rarity]`
- `achievementBonus` — `card.achievements.length × economyInfo.cardValues.achievementBonus`
- `totalValue` — `card.value` (уже посчитано на бэке)

Загрузка `economyInfo` — через существующий `fetchEconomyInfo` (уже используется в `HelpPage`, `CardsPage`).

### 5. Ценность на карточке при сборке команды

**Файл:** `polemica-fantasy-webapp/src/pages/TeamPage.tsx`

При выборе карт для команды — показать ценность каждой карты (бейдж). Это подготовка к бюджетной лиге (План 6), но уже полезно для понимания ценности.

### 6. Ценность в Player-grouped view

**Файл:** `polemica-fantasy-webapp/src/components/PlayerGroupedView.tsx`, `PlayerCard.tsx`

В режиме просмотра коллекции по игрокам — бейдж ценности на каждой карточке стека.

### 7. Суммарная ценность выпавших карт в PackOpening

**Файл:** `polemica-fantasy-webapp/src/components/PackOpening.tsx`

После открытия пака — показать «суммарная ценность: 175₱» (сумма `value` выпавших карт). Ощущение ценности покупки (§5.3).

### 8. Ценность в справке (`/help`)

**Файл:** `polemica-fantasy-webapp/src/pages/HelpPage.tsx`

Новая секция «Ценность карты»:
- Формула: `ценность = базовая (по редкости) + количество достижений × бонус`
- Таблица значений (из `economyInfo.cardValues`):

| Редкость | База | Ач. (типовые) | Итого |
|----------|------|---------------|-------|
| COMMON | 25 | 0 | 25 |
| RARE | 40 | 10 | 50 |
| EPIC | 80 | 20 | 100 |
| LEGENDARY | 370 | 30 | 400 |

- Пояснение: ценность ≠ цена на маркетплейсе ≠ стоимость переработки
