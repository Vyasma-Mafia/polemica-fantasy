# План 4: Глобальный рейтинг (frontend)

> **Предусловия:** План 3 (API `GET /api/v1/rating` доступен)  
> **Результат:** TMA показывает страницу глобального рейтинга с навигацией  
> **Дизайн-документ:** §8.2 (Глобальный рейтинг)

---

## Шаги

### 1. Типы: DTO рейтинга

**Файл:** `polemica-fantasy-webapp/src/api/types.ts`

```typescript
interface RatingEntry {
  rank: number;
  user: UserPublic;
  fantikiBalance: number;
  cardsValue: number;
  totalValue: number;
  cardsCount: number;
}

interface GlobalRating {
  entries: RatingEntry[];
  currentUser: RatingEntry | null;
}
```

### 2. API-клиент

**Файл:** `polemica-fantasy-webapp/src/api/rating.ts` (новый)

```typescript
export async function fetchGlobalRating(initData: string): Promise<GlobalRating> {
  return apiGet('/api/v1/rating', initData);
}
```

### 3. Страница `RatingPage`

**Файл:** `polemica-fantasy-webapp/src/pages/RatingPage.tsx` (новый)

Структура:
- Заголовок «Рейтинг» (с `PageHeader`)
- Таблица рейтинга: ранг, ник, баланс фантиков, ценность карт, итого
- Текущий пользователь выделен (жирный шрифт / фоновый цвет)
- Если текущий пользователь далеко в списке — прилепленная строка внизу (аналог `LeaderboardPinnedBlock` из серийного лидерборда)

Колонки таблицы:

| # | Игрок | ₣ | ₱ | Всего |
|---|-------|---|---|-------|
| 1 | PlayerOne | 5 000 | 12 000 | 17 000 |

Адаптация под мобильный экран:
- Компактные числа (без «фантиков», только иконки ₣ / ₱)
- Горизонтальный скролл если не влезает, или свёрнутые колонки

### 4. Маршрут

**Файл:** `polemica-fantasy-webapp/src/App.tsx`

Добавить маршрут:

```tsx
<Route path="/rating" element={<RatingPage />} />
```

### 5. Навигация

**Файл:** `polemica-fantasy-webapp/src/App.tsx`

Добавить пункт «Рейтинг» в навигацию `<nav>`. Расположение: между «Коллекция» и «Справка» (или в конце — зависит от приоритета).

Текущая навигация: Турниры | Коллекция | Справка | Маркетплейс | Магазин  
С рейтингом: Турниры | Коллекция | **Рейтинг** | Справка | Маркетплейс | Магазин

**Внимание:** 6 пунктов навигации может быть тесно на мобильном экране. Возможные решения:
- Иконки вместо текста для части пунктов
- Скроллабельная навигация
- Рейтинг как подстраница (например, доступен из профиля)

### 6. Стили

**Файл:** `polemica-fantasy-webapp/src/index.css`

Стили для таблицы рейтинга:

```css
.pf-rating-table { /* таблица */ }
.pf-rating-row { /* строка */ }
.pf-rating-row--current { /* текущий пользователь */ }
.pf-rating-pinned { /* прилепленная строка текущего пользователя */ }
```

Визуальный стиль — консистентный с `LeaderboardPage` (серийный лидерборд), но с дополнительными колонками.

### 7. Справка

**Файл:** `polemica-fantasy-webapp/src/pages/HelpPage.tsx`

Добавить секцию «Глобальный рейтинг»:
- Формула: `рейтинг = баланс фантиков + Σ ценностей всех карт`
- Что учитывается: все карты (даже израсходованные, даже на маркетплейсе)
- Что влияет: открытие паков, победы в сериях, переработка, покупки/продажи
- Ссылка на страницу рейтинга
